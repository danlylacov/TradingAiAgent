# TechAnalyst

Технический анализ акций из состава IMOEX. Свечи, индикаторы и уровни считаются по локальной истории. Отчёт сверяется с последним закрытым баром и сохраняется вместе с графиком.

## Данные

Минутные свечи OHLCV лежат в MongoDB, база `techanalyst`. Документ свечи уникален по паре `(ticker, begin)`. Закрытый день не перезаписывается, текущий день заменяется целиком.

Рядом хранятся состав индекса (`universe`), последний срез котировок (`quotes`) и статус докачки (`backfill`). Время свечей — московское.

Старшие таймфреймы собираются из минуток: `5m`, `15m`, `1h`, `1d`, `1w`. Пустые интервалы не заполняются. Агрегация: open — первое значение, high — максимум, low — минимум, close — последнее, volume и value — сумма. Индикаторы считаются только по закрытым барам: последний бар отбрасывается, пока его интервал не закончился.

Параметр `until` обрезает историю этой датой включительно. Инструменты не отдают бары и котировку позже неё.

## Индикаторы

Считаются по уже переданным барам, без заглядывания вперёд.

| Семейство | Колонки | Параметры |
| --- | --- | --- |
| SMA | `sma_20`, `sma_50`, `sma_200` | среднее закрытий |
| EMA | `ema_12`, `ema_26` | множитель `2/(N+1)` |
| RSI | `rsi_14` | период 14 |
| MACD | `macd`, `macd_signal`, `macd_hist` | 12, 26, сигнал 9 |
| Полосы Боллинджера | `bb_mid`, `bb_upper`, `bb_lower`, `bb_width` | SMA 20 ± 2 стандартных отклонения; ширина = `(верх − низ) / середина` |
| ATR | `atr_14` | средний истинный диапазон, 14 |
| Стохастик | `stoch_k`, `stoch_d` | %K за 14 баров, %D = SMA(%K, 3) |
| OBV | `obv` | объём прибавляется при росте закрытия и вычитается при падении |

## Структура

`get_structure` читает до 1500 закрытых баров и возвращает обзор, а не сами свечи: `window_high`, `window_low`, медиану объёма за 20 баров и за всё окно, ATR.

Свинг — экстремум среди трёх баров слева и справа. Соседние свинги в пределах `0.5 ATR` склеиваются в зону поддержки или сопротивления. На дневках `window_high` и `window_low` используются как диапазон периода (`week52`).

## Разбор

Фон читается по неделе и дню. Если выбранная свеча не `1d` и не `1w`, вход решается по ней, а неделя и день остаются фоном.

Карта уровней: три поддержки ниже цены и три сопротивления выше. Ближайшие — S1 и R1. Тип уровня: свинг, круглое число, консолидация, SMA200 или экстремум окна. «Экстремум окна» ставится только на `window_high` или `window_low`.

Фигура ищется в последних 60 барах выбранной свечи. Два экстремума двойной вершины или двойного дна должны лежать в пределах `0.5 ATR`, иначе фигуры нет. Нет фигуры — пуск и цель пустые.

Табель из девяти строк. Веса: цена/SMA20 — 3, цена/SMA50 — 3, цена/SMA200 — 4, крест — 4, RSI — 3, MACD — 3, полосы — 2, объём — 2, OBV — 2. Сумма весов 26. Стохастик в табель не входит. Если SMA50 или SMA200 нет в баре, строка средней и креста нейтральные.

Сделка:

- стоп = середина зоны входа ∓ `1.5 × ATR`;
- две цели — следующие уровни по ходу;
- прибыль/риск = `(цель − середина входа) / (середина входа − стоп)` для покупки, для продажи зеркально;
- конфликт недели и дня или равные веса — уклон нейтральный, рекомендация `hold`, оценка не выше 6;
- совпадение таймфреймов и перевес бычьих весов при не падающей неделе — только `buy`; зеркально — только `sell`.

Числа цены, средних, RSI, MACD, стохастика, ATR, ширины полос и отношения объёма к медиане 20 сверяются с последним закрытым баром выбранной свечи. Расхождение с данными отчёт не проходит.

## Инструменты

| Инструмент | Что возвращает |
| --- | --- |
| `get_universe` | тикеры состава IMOEX и веса |
| `get_candles` | последние свечи OHLCV, не больше 400 баров |
| `get_indicators` | закрытые бары с индикаторами, не больше 400 |
| `get_quote` | последний сохранённый срез; при `until` — закрытие последнего бара |
| `get_structure` | свинги, зоны, экстремумы окна, медианы объёма |
| `search_knowledge` | до пяти статей по словам запроса |
| `get_topic` | статья: `trend_levels`, `market_structure`, `chart_patterns`, `moving_averages`, `rsi`, `macd`, `bollinger`, `atr_stop`, `volume`, `score_rubric` |
| `plot_analysis` | PNG цены, объёма, RSI и MACD с уровнями, входом, стопом и точками фигуры |

## Отчёт

Каталог `agent/reports/<тикер>_<свеча>[_дата]/`:

- `report.json` — рекомендация, оценка 1–10, уклон, тренд, импульс, волатильность, уровни, фигура, табель, сделка и обоснование;
- `report.md` — те же разделы текстом;
- `chart.png` — график, путь на который ссылается отчёт.

`POST /analyze` отдаёт zip из `report.md` и `chart.png`. Параметры: `ticker`, `candle` (по умолчанию `1d`), `until` (`YYYY-MM-DD`). `GET /candles` возвращает список размеров свечи.
